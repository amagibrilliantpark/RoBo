🔌 Backend beklentisi — opencode (gerçek) nasıl çalışıyor

Bu mocklar “sadece tasarım”. Gerçek ekleme akışında RoBo desktop-app şu iki çağrıyı yapmalı. Senin istediğin custom OpenAI-compatible provider bununla uyumlu:

// 1) Provider tanımını opencode config'e yaz (built-in değil, custom)
//    opencode.json → provider.*
PATCH /config
{
  "provider": {
    "my-provider": {
      "name": "My Provider",
      "baseURL": "https://api.example.com/v1",
      // optional: models, headers vs — opencode dokümanına göre
      "models": {
        "gpt-4o": { "name": "GPT-4o" },
        "gpt-4o-mini": { "name": "GPT-4o Mini" }
      }
    }
  }
}

// 2) Credential'ı auth store'a yaz (Studio'ya gitmez, sadece local opencode)
PUT /auth/my-provider
{ "apiKey": "sk-..." }              // bazı provider'larda { "apiKey": "...", "baseUrl": "..." } de gerekebilir
// veya OpenCodeClient.setAuth(id, credentials) → ipc-provider.js → opencode-client.js → fetch PUT /auth/{id}

// 3) Listeyi yenile
GET /provider         // → providers.all + providers.connected güncellenir
GET /provider/auth    // → authMethods — custom provider burada yoksa isCustomProvider=true sayılır

Not: Şu anki RoBo kodunda (desktop-app/src/main/opencode-client.js:166 ve ipc-provider.js:36) PUT /auth/{id} var ama PATCH /config ile custom tanım yazan bir akış henüz yok — bu mocklar o akışın UI'ını tasarlamak için.
